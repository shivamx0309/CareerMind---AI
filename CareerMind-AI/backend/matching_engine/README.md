# Matching Engine (`backend/matching_engine`)

## Overview
The Matching Engine calculates multi-faceted alignment scores between candidate resumes and target job descriptions.

## Responsibilities
- **Hybrid Similarity Scoring**: Combine cosine vector similarity, weighted skill overlap, experience level compatibility, and education criteria.
- **Gap Analysis**: Identify missing critical hard skills, optional skills, and credential gaps.
- **Actionable Recommendations**: Provide candidates with targeted suggestions to increase interview eligibility for a given job posting.
