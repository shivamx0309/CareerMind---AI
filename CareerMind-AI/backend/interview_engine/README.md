# AI Interview Simulator Engine (`backend/interview_engine`)

## Overview
The Interview Engine simulates dynamic technical, behavioral, and situational job interviews tailored to candidate profile and target job role.

## Responsibilities
- **Adaptive Question Generation**: Generate role-specific technical and behavioral questions (STAR format) dynamically based on resume claims.
- **Multimodal Evaluation**: Assess candidate responses on technical accuracy, clarity, confidence, and conciseness.
- **Real-Time Rubric Scoring**: Generate comprehensive post-interview feedback, score breakdown, and suggested ideal answers.
