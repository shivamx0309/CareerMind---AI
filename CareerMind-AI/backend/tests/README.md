# Test Suite (`backend/tests`)

## Overview
Houses all automated testing suites, test fixtures, mocks, and benchmarking scripts for the backend application.

## Structure
- `unit/`: Fast unit tests for isolated functions, schema validations, and engine algorithms.
- `integration/`: End-to-end API tests with test database transactions and mock AI services.
- `conftest.py`: Shared pytest fixtures, mock clients, and async test runners.
