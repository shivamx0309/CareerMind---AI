# Sample Data (`sample_data/`)

## Overview
Contains sanitized, anonymized sample resumes and realistic job postings for development, unit testing, and benchmarking.

## Subdirectories
- `resumes/`: Anonymized sample resumes across diverse industries and experience tiers (Junior, Mid, Senior, Lead).
- `job_descriptions/`: Curated sample job descriptions for Software Engineering, Data Science, Product Management, etc.
