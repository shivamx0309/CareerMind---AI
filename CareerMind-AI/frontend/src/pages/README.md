# Page Views (`frontend/src/pages`)

## Overview
Route-level page containers representing primary screens and features in CareerMind AI.

## Key Pages
- **Dashboard**: High-level candidate overview, recent analyses, quick action metrics.
- **ResumeAnalyzer**: Interactive resume uploader, ATS audit report, and section breakdown.
- **JobMatcher**: Job description input, real-time match percentage, and skill gap visualization.
- **InterviewSim**: Real-time AI mock interview console with speech/text prompt simulator.
- **KnowledgeHub**: Career path exploration, skill taxonomy reference, and interview question bank.
