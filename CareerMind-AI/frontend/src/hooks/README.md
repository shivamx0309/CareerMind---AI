# Custom Hooks (`frontend/src/hooks`)

## Overview
Encapsulated reusable state logic, side-effects, and reactive browser API abstractions.

## Key Hooks
- `useAuth`: Access current user session, token refresh, and login/logout methods.
- `useResume`: Handle resume upload lifecycle, progress tracking, and parsed response state.
- `useJobMatch`: Reactive hook to trigger matching calculations and cache comparison results.
- `useInterview`: Manage interview session state machine, timer, and question turns.
