# Layouts (`frontend/src/layouts`)

## Overview
Structural layout wrappers providing consistent navigation shells, headers, and footers across page routes.

## Modules
- `MainLayout`: Authenticated application shell with responsive sidebar, top navbar, and content container.
- `AuthLayout`: Centered, distraction-free container for login, registration, and password recovery.
- `Sidebar`: Collapsible application navigation menu with route highlights.
