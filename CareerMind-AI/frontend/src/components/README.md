# UI Components (`frontend/src/components`)

## Overview
Contains reusable, atomic, and domain-agnostic UI elements used across different views in CareerMind AI.

## Categories
- **Core Elements**: Buttons, text inputs, dropdowns, modal dialogs, tooltips, badges.
- **Data Display**: Score progress bars, skill chips, match radar charts, ATS rating gauges.
- **Feedback & States**: Skeleton loaders, alert banners, confirmation dialogs, toast notifications.
