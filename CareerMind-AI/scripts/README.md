# Automation & Utility Scripts (`scripts/`)

## Overview
Executable automation scripts for environment setup, database migrations, model downloads, and data preprocessing.

## Examples
- `download_models.py`: Automatically fetch required pre-trained weights from HuggingFace.
- `seed_database.py`: Populate PostgreSQL with initial admin accounts and role categories.
- `build_skill_graph.py`: Parse ESCO/O*NET skill taxonomies and generate local lookup indices.
