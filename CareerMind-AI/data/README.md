# Data Directory (`data/`)

## Overview
Storage location for local raw datasets, processed feature tables, and temporary uploaded documents.

## Directory Structure
- `raw/`: Unmodified raw datasets and benchmark files.
- `processed/`: Cleaned, tokenized, and normalized datasets ready for model consumption.
- `uploads/`: Temporary local storage for uploaded candidate resumes and job descriptions.

## Privacy & Security
All files placed in `data/` are strictly ignored by Git to comply with privacy regulations and avoid repository bloat.
